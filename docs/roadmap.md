# Roadmap

## Now

- Public brand site with cinematic home, inventory, details, about, contact, and journal routes.
- Garage OS dashboard and inventory CRUD.
- Ktor inventory API with PostgreSQL persistence.
- Flyway schema and seed data.
- Docker Compose for local backend.
- GitHub Actions for frontend build and backend build.

## Next

- Vehicle project tabs: expenses, repairs, documents, timeline, financials.
- Real photo storage workflow.
- Lead capture persistence.
- Admin analytics fed by actual expenses and vehicle lifecycle events.
- GitHub Pages deployment workflow with repository-specific environment values.
- Backend integration tests running against ephemeral PostgreSQL.

## Later

Do not build these until the dealership workflow demands them:

- Authentication and roles.
- VIN decoding.
- Marketplace integrations.
- Auction imports.
- AI inspection assistant.
- Pricing recommendations.
- Accounting and dealer compliance.
- Customer portal.
